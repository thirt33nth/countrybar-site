Эта страница описывает обработку данных в приложении CountryBar и на его сайте поддержки. Разработчик проекта — thirt33nth.

Какие данные использует приложение

CountryBar определяет публичный IP-адрес подключения и соответствующую ему страну, чтобы показать флаг в строке меню macOS. Приложение не запрашивает доступ к GPS или службам точной геолокации, контактам и файлам пользователя.

Запросы к внешнему сервису

Для определения страны приложение напрямую отправляет HTTPS-запрос на ipwho.is (IPWHOIS.IO). Провайдер видит публичный IP, с которого пришёл запрос. Его ответ может включать IP, страну, регион, город, приблизительные координаты и сведения о сети; CountryBar извлекает из ответа IP и код страны для отображения.

Запрос выполняется при запуске, при изменениях сети, после пробуждения Mac, каждые пять минут во время работы и при нажатии «Обновить». Некоторые сетевые события могут объединяться в один запрос.

Провайдер самостоятельно обрабатывает запросы и может сохранять технические журналы, в том числе IP-адреса. Его правила хранения и обработки описаны в политике IPWHOIS.IO. CountryBar не контролирует серверные журналы провайдера и не обещает их отсутствие.

Хранение на Mac и серверы разработчика

Текущая версия использует временную сетевую сессию и держит результат в оперативной памяти. Код приложения не записывает историю IP и стран на диск и не отправляет её на серверы разработчика. В CountryBar нет встроенных рекламных или аналитических SDK, пользовательских аккаунтов и отслеживания между приложениями.

Сайт и обращения в поддержку

Эти страницы размещены на GitHub Pages, без добавленных нами счётчиков, сторонних шрифтов и рекламных скриптов. GitHub обрабатывает технические данные посещения согласно своей политике конфиденциальности.

Если вы создаёте обращение в GitHub Issues, имя вашего аккаунта и содержимое обращения становятся публичными. Разработчик использует предоставленные сведения для ответа и исправления проблем. Не включайте в обращение IP, пароли или иную конфиденциальную информацию. Управление данными аккаунта и публикаций производится средствами GitHub.

Ваш выбор и вопросы

Чтобы прекратить запросы приложения, выберите «Выйти» в меню CountryBar. Удаление приложения прекращает его дальнейшее использование; это не удаляет журналы, которые могли быть сохранены внешними сервисами.

Общие вопросы о конфиденциальности можно направить через поддержку проекта, без размещения персональных данных. По вопросам обработки и удаления данных на стороне IPWHOIS.IO используйте контакты, указанные в его политике; по данным GitHub — инструменты и контакты GitHub.
